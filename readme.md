# Learning in public

This repository is to document my journey of learning programming languages, frameworks through small structured hands-on projects. The goal is to build a strong understanding by creating practical things, starting from the basics and gradually progressing toward more advanced concepts.

Rather than relying only on tutorials, each concept is explored through small experiments and incremental projects, making it easier to retain knowledge and track progress over time.

### 📌 Focused topics

- [Rust](https://rust-lang.org/) - active
- [Go](https://go.dev/)
- [Python](https://www.python.org/)

### 📂 Project structure

Each programming language is organized into its own directory. Projects are numbered to indicate their progression.

```
root
├── rust
│   ├── 01-hello-world
│   ├── 02-variables
│   ├── 03-control-flow
│   └──  ...
```

Each project is small, centered around a single core concept, and reinforced over previous learning.
